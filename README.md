# Waffle's NixOS Configuration
This repository contains my NixOS system configurations for my desktop and laptop.

## Why NixOS?
I got bored and tired of Arch. I messed with some Atomic Fedora distros but after watching some videos, NixOS struck me as more appealing from a configuration and development standpoint.
